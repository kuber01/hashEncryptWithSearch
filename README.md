# Заполнение хэш-таблицы с возможностью поиска идентификаторов

Учебный проект по реализации хэш-таблицы, выполненный на 4 курсе университета. Программа загружает идентификаторы из текстового файла, вычисляет для них хэш-значения, сохраняет их в таблице с обработкой коллизий и позволяет выполнять поиск идентификаторов.

Ниже представлена краткая информация о проекте. Детальная информация приложена в файле "Отчет о выполнении работы"

## Цель проекта

- изучить принципы работы хэш-таблиц;
- реализовать механизм разрешения коллизий;
- реализовать поиск данных в хэш-таблице.

## Принцип работы

1. Пользователь загружает текстовый файл с идентификаторами. После загрузки программа пишет информацию о количестве коллизий в таблице.
2. Для каждого идентификатора вычисляется хэш.
3. Хэш определяет позицию элемента в таблице.
4. При возникновении коллизии используется упорядоченный список с логарифмическим поиском.
5. Пользователь может выполнить поиск идентификатора и получить количество сравнений, необходимое для его нахождения.
